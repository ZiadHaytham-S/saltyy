# تأثيرات الواجهة والانتظار — 12 أكتوبر 2026

تعديل UI داخل النطاق الحالي، بدون تغيير API أو إضافة dependencies أو خدمات مدفوعة.

تغيير اللغة يستخدم React useTransition لانتظار تحديث Server Components، ثم Fade قصير. لا نعيد تركيب شجرة التطبيق بمفتاح Locale، حتى لا تضيع بيانات النماذج أو Receipt/Recovery Tokens. المظهر يتغير فورًا مع موجة زرقاء شفافة من موضع الزر، ثم تثبيت Cookie وتحديث السيرفر. التأثيرات لا تمنع الضغط على بقية الصفحة.

SalltyLoader أيقونة شنطة SVG وحركة CSS، مشتركة بين الأزرار والصفحات والسلة والتأكيد. Button تقبل loading مع إبقاء مساحة الزر واسمه لقارئ الشاشة وتعطيل الضغط أثناء العمل. لا توجد نسب مئوية وهمية أو تأخير للعمليات لإظهار الحركة.

mutate وuploadImage يبدآن Activity وينهيانها داخل finally، سواء نجح الطلب أو فشل. العداد يغطي الطلبات المتزامنة، والمؤشر العام غير حاجب للنقر. نصوص الانتظار محفوظة كأوصاف وصول مخفية، بينما الرسائل المهمة والنجاح والأخطاء تبقى واضحة. لا يُعامل الضغط المحلي الفوري، مثل زيادة كمية السلة، كطلب شبكة وهمي.

إعداد prefers-reduced-motion يوقف حركة الشنطة وتأثيرات اللغة والمظهر. Dashboard Layout يوجّه الحساب بلا متجر إلى Onboarding قبل بث Loading، للحفاظ على مسار إنشاء المتجر السابق.

الملفات المهمة: components/ui/sallty-loader.tsx، components/ui/button.tsx، components/preferences.tsx، components/activity-indicator.tsx، lib/activity.ts، lib/api/client.ts، app/globals.css وLoading routes. الاختبار يستخدم طلب شحن مؤخرًا للتحقق من ظهور المؤشر وتعطيل الزر واختفائه بعد النجاح، وتقليل الحركة، بالإضافة إلى رحلة الحسابات والطلبات الحالية.

توحيد التحميل على مستوى التطبيق: PageLoader تستخدم نفس شنطة Sallty في root loading وكل ملفات تحميل لوحة التاجر والمتجر، بدون نصوص انتظار ظاهرة أو Skeleton مختلف. اختبارات Redirect تقبل التحويل HTTP 307 أو meta redirect بعد بدء Streaming وفق سلوك Next.js الرسمي، وتتحقق من الوجهة الفعلية؛ اختبارات المتصفح تستمر في التحقق من الحماية والتنقل.
